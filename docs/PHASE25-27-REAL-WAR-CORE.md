# Phase 25–27 — Real War Core

## Phase 25: Supply + Power
- Supply Depot is an early logistics building.
- Generator provides 100 power. HQ provides baseline 25 power.
- Barracks, factories, helipads, airbase, radar, refinery, bunker and AA consume power.
- Power shortage slows construction/production and blocks heavy production when severe.

## Phase 26: Command / build tree
- Barracks requires Generator.
- Factory, Helipad and Bunker require Barracks.
- Airbase requires Helipad.
- Radar requires Supply Depot.
- AA requires Radar.
- Building limits prevent unlimited spam.
- Air command becomes available through the Airbase.

## Phase 27: Force limits
- Global unit caps are enforced for the major combat classes.
- Production queues count toward caps, so queues cannot bypass limits.
- AI uses the same production/build restrictions as the player.

The intended loop is: HQ → Supply → Generator → Barracks → Factory/Helipad → Airbase/Radar → combined arms.
