# Phase 64 — Command & Logistics Warfare

## Logistics doctrine
- Road convoys move physical resource cargo into depot stock.
- Depot stock is split into ammo, fuel and repair capacity.
- A team can prioritize one stock channel: ammo / fuel / repair / balanced.
- Front-line units consume depot stock when rearming/refueling.
- Engineers repairing structures consume repair stock.

## Network
- HQ and depots form a connected network.
- Bridges can be damaged/destroyed; destroyed bridges break the nearby depot connection.
- Destroyed road infrastructure forces convoys to stop at the obstruction.
- Convoys can be intercepted by hostile units near the route; cargo is lost on destruction.

## Operational effect
Supply is deliberately soft, not binary. Units progressively lose supply, then morale and combat effectiveness as the network dries up. This keeps an isolated battlegroup useful for a while instead of making it instantly useless.

## Intended next layer
Command radius, explicit FOB placement, alternate convoy routes, escort orders, engineer bridge repair and manual logistics priorities should be surfaced as direct player commands/UI.
