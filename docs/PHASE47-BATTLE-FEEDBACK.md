# Phase 47 — Battle Feedback & Unit Animation

- Muzzle flashes and short-lived point lights on weapon fire.
- Impact sparks and dust on hits.
- Procedural hover/bob animation for helicopters and aircraft.
- March/bob animation for infantry and special forces.
- Subtle vehicle suspension vibration.
- GLB rotor support via an optional `Rotor` node.
- Effects are capped to protect GPU/CPU frame time.
- PostFX fields are optional-safe when post-processing is disabled.

The goal is a stronger Real War-style battlefield feel without reintroducing expensive full-scene post processing.
