# Phase 24 – Real War style base loop

Skirmish opens with HQ, two engineers and two logistics helicopters. Combat units are produced only after the player builds the required production facilities.

## Build progression
- HQ: starting command/economy anchor
- Barracks: infantry + engineers
- Factory: requires Barracks; tanks + artillery
- Helipad: requires Barracks; helicopters + transports
- Airbase: requires Helipad; fighters
- Supply depot: forward construction/supply radius
- Refinery: must be placed at a resource point
- Radar: requires Supply; expands command/intelligence infrastructure
- AA: requires Radar
- Bunker: requires Barracks

Buildings must be connected to an HQ, supply depot, or refinery construction area. Supply depots create forward expansion points.

## Intended loop
HQ -> resource helicopters -> credits/material -> engineer construction -> production buildings -> army -> forward supply/refinery -> airbase/radar/AA -> combined-arms attack.
