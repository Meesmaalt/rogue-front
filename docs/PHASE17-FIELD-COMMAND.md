# Phase 17 – Field Command

- Production buildings have rally points.
- Right-click ground with a selected Barracks/Factory/Helipad sets its rally point.
- Newly produced combat units move to the rally point automatically.
- Rally points persist in save/load.
- AI now uses the same production queue path as the player instead of spawning combat units directly.
- Production costs are charged to the correct team wallet in multiplayer/AI simulation.
- Existing selection groups, attack-move, hold, patrol and transport controls remain compatible.
