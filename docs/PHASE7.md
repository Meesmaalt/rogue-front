# Faas 7 – Heli ja UI viimistlus

- Web Audio helikiht sündmustele: tuli, tabamus, plahvatus ja madal taustarütm.
- Seaded salvestatakse brauserisse: master/SFX/music helitugevus, graafika profiil ja põhilised klahvid.
- Paus peatab simulatsiooni, sisendi ja heli; jätkamine taastab mängu.
- HUD-is on paus, salvesta, lae ja seadete juhtimine.
- Eesmärkidel on progressiriba, tootmisnuppudel tooltipid ja baasi madala HP hoiatus.
- Ründeliikumise režiim annab visuaalse kursori oleku.
- Puute jaoks jääb mobiilipaigutus kasutatavaks; põhisisend on endiselt hiire/klaviatuuri RTS-mudel.
