# Phase 51 — Real War command tree + producer upgrades

This phase moves the base loop toward the original Real War / Rogue States structure.

## Command centers

HQ + generator unlock the three command branches:
- Land Command Center
- Air Command Center
- Sea Command Center

These unlock the appropriate producer branches instead of putting every producer directly behind HQ.

## Producers

- Land Command -> Barracks, Vehicle Factory, Combat Engineering Center
- Air Command -> Helipad, Airbase
- Sea Command -> Shipyard
- Strategy Centers unlock producer level 2

Producer level 2 is a real upgrade stored on the producer entity and saved with the game.

## Producer level 2

- Barracks -> Special Forces
- Vehicle Factory -> Artillery
- Helipad -> Gunship
- Shipyard -> Destroyer / Submarine

The upgrade costs 260 Supply + 260 credits and requires the appropriate strategy center.

## Save

Save version is 12. Older versions remain loadable.
