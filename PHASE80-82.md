# Rogue Front — Phase 80–82

## 80 Battlegroup
The existing Wargame-inspired deck is now backed by a match-level battlegroup state: purchased/deployed/lost cards, activation budget, command reserve and veterancy.
Production consumes battlegroup availability and deaths are recorded.

## 81 Campaign
Persistent campaign progression has prerequisites, command XP and doctrine rewards. Existing missions are reused, so this is backwards-compatible with the current content.

## 82 Game modes
Skirmish selection now exposes:
- Skirmish
- Conquest
- Breakthrough
- Attrition
- Assault

The mode controller is simulation-side and can later be reused by multiplayer/server rules.
