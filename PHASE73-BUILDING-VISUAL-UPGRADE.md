# Phase 73 — Building Visual Upgrade 2.0

Building levels now have architectural silhouettes instead of only small upgrade markers.

- HQ / Command / Strategy: command wings + communications mast + elevated sensor dish.
- Factory: production wings, industrial modules, storage silos and taller central hall.
- Barracks: additional accommodation wings and communications mast.
- Supply: warehouse wings + storage tanks/silos.
- Airbase / Helipad: additional service buildings and taller operational infrastructure.
- Refinery: visible tank farms and processing structures.
- Radar: mast and large radar dish.
- Generator: additional generator blocks and fuel/storage unit.
- Shipyard: additional industrial halls and crane/mast silhouette.
- Bunker / AA: reinforced modules and elevated defensive equipment.

The base therefore becomes visibly more developed as its building levels increase.
